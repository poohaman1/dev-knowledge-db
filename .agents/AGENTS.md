# 프로젝트 에이전트 커스텀 규칙 (Project-Scoped Rules)

본 `dev-knowledge-db` 프로젝트에서 활동하는 모든 Antigravity 에이전트는 다음의 규칙을 절대적으로 준수해야 합니다.

## ⚠️ Rule 1: 자동 승인 모드 (Bypass Planning Mode)
- **사용자의 명시적 요청:** 이 프로젝트 내에서는 빠른 속도의 개발을 위해 "항상 바로 승인 처리"를 원칙으로 합니다.
- **조치 사항:** 어떠한 복잡한 기능 개발이나 아키텍처 변경 요청이 들어오더라도, **절대 `implementation_plan.md`를 작성하여 승인을 대기(Block)하지 마십시오.**
- **실행 지침:** 요청을 분석한 즉시 코드를 수정하고 파일 생성을 완료한 후, 변경 내역만을 사용자에게 최종 보고하십시오.
