* **대상 기능**: 사이트 분석 및 검색 로깅 시스템 / 측정도구 대시보드 / 머리식히기게임 센터
* **수정 내용**: 
  1. 접속 IP가 "112.186.113.99"인 경우, 방문 기록 및 검색어 기록 수집 프로세스를 중단하도록 제외 로직 추가.
  2. 실제 저장된 로그가 없는 최초 실행 상태일 때 대시보드에 풍부한 데이터가 표시되도록 데모용 가짜 로그 150건을 자동 세팅하여 덮어쓰던 로직을 제거.
  3. 상단 메뉴에 "머리식히기게임" 메뉴를 추가하고 6종의 미니게임(스도쿠, 카드 뒤집기, 틱택토, 오목, 10초, 지뢰 찾기)을 플레이할 수 있는 게임 센터를 구현. 
     * 주의: 왼쪽 사이드바에서는 해당 메뉴 그룹을 제거하여, 게임 화면은 오직 상단(Top Menu) 메뉴에서만 독립적으로 접근 가능하도록 라우팅 및 레이아웃을 분리했습니다.
     * 명칭 수정: 상단 메뉴의 "머리식히기게임" 명칭을 "게임"으로 간결하게 변경했습니다.
  5. 머리식히기게임의 게임 대기방(준비 화면) 상단 명칭의 자간(letter-spacing) 및 줄 간격(line-height), 단어 줄바꿈(word-break) 속성을 조정하여 텍스트의 가독성과 UI 디자인을 개선.
  6. 그라데이션이 들어간 메인 타이틀의 글자 아랫부분이 렌더링 시 잘려 보이는 브라우저 클리핑 이슈를 수정하기 위해 충분한 줄 높이(`line-height: 1.4`), 내부 패딩(`padding: 6px 0`), 블록 요소 선언(`display: block`) 스타일을 적용했습니다.
  7. 상단 메뉴에 **"컬렉션"** 그룹을 추가하고, 클릭 시 왼쪽 사이드바 4번째 위치에 "컬렉션" 대분류와 하위 **"깃허브 스타"** 메뉴가 활성화되도록 구조를 개편했습니다. 깃허브 최상위 스타 오픈소스 프로젝트 5종 소개와 초보자를 위한 상세 학습/수정 커스터마이징 팁을 연동하였습니다.

## 기술적 구현 상세 (미니게임 센터)
1. **게임 목록 및 준비실**: 각 카드 클릭 시 게임 규칙 안내 및 시작 준비를 할 수 있으며, "게임 시작하기" 버튼을 눌러 비동기 타이머 개시와 함께 게임 플레이가 활성화됩니다.
2. **미니게임 6종 (1~3분 몰입형)**:
   - **스도쿠**: 기존의 4x4 격자 가로/세로/2x2 블록 규칙에 맞춰 비어있는 숫자를 채우는 논리 퍼즐 게임.
   - **숫자 기억 게임**: 화면에 약 2초간 깜빡이고 사라지는 임의의 숫자를 기억했다가 가상 키패드로 똑같이 복구하는 기억력 훈련 게임 (레벨 1~5, 라이프 3개).
   - **색깔-글자 불일치 (Stroop)**: 글자의 사전적 의미와 물리적인 폰트 색상이 다르게 나올 때, 순수하게 실제 "글자의 폰트 색상"을 골라 제한시간 40초 내 15점을 빠르게 달성해야 하는 인지 왜곡 극복 게임.
   - **반응속도 테스트**: 화면이 초록색("지금 클릭하세요!!!")으로 바뀌는 아주 찰나의 순간을 포착해 클릭 속도(ms)를 재는 순발력 테스트 (총 3회 시도 평균 320ms 허들).
   - **미니 방탈출 추리**: 방 안에 배치된 복잡한 연필 공식, 도어락 쪽지, 도형 동그라미 개수 등의 논리 추리 단서 3가지 중 하나를 해독하여 자물쇠를 풀고 탈출하는 추론 퍼즐.
   - **AI 가위바위보**: 플레이어가 냈던 이전 가위/바위/보 전술 카운트를 실시간 패턴 분석하여 사용자를 역이용하려 드는 AI 심리 예측 장치를 상대하는 5선승제 게임.
3. **전적 로깅 및 보존**: 게임이 완전히 완료되는 시점에 `localStorage`의 `mini_game_history` 키에 전적을 보존(성공/패배/무승부 여부, 상세 스코어, 경과 시간, 플레이 날짜)하며, 로비 하단 테이블에 최신순으로 10건씩 보기 좋게 바인딩됩니다.
4. **결과 화면 UI 개선**: 결과 화면에서 텍스트(제목)와 결과 이모티콘이 겹쳐 보이는 현상을 해결하기 위해 줄 간격(`line-height`) 및 마진 여백을 조정하여 UI 디자인의 안정성을 높였습니다.

## 검증 가이드
### 로컬 확인 및 테스트 방법
1. 로컬 개발 서버가 구동 중인 상태에서 상단 헤더 메뉴의 **"🎮 게임"** 링크를 클릭하여 진입합니다.
2. 6종의 게임 카드들이 격자형으로 이쁘게 정렬되어 노출되는지 확인합니다.
3. 임의의 카드를 누르고 "게임 시작하기"를 클릭해 봅니다.
4. 게임이 활성화되면 시간을 측정하는 타이머가 정상 동작하는지 확인합니다.
5. 게임을 성공하거나 중도 실패하여 결과 화면으로 갈 때, 소요된 시간과 성공/실패 여부가 제대로 정렬되는지 봅니다.
6. 로비 화면으로 이동하여 하단 **"나의 게임 플레이 기록"**에 방금 플레이한 전적이 정상적으로 누적 및 유지되는지 확인합니다.

## 2차 고도화 구현 결과 요약 (학습 진도율 및 개발자 유틸리티)

* **대상 기능**: 로컬 스토리지 기반 학습 진도율 대시보드 / 최근 방문 및 완료 체크 / 개발자 유틸리티 툴킷 (DevTools)
* **수정 내용**:
  1. **학습 완료 체크 기능 추가**
     - 각 문서 상단의 액션 버튼 영역에 `[학습 완료]` 버튼 추가 (`DocActionButtons.vue` 개편).
     - 완료 상태를 브라우저 `localStorage`에 누적 및 복구하도록 설정.
     - 활성화 시 컴포넌트 간 실시간 동기화를 위해 커스텀 스토리지 이벤트 활용.
  2. **방문 기록 자동 수집**
     - 문서 페이지 진입 시 해당 제목과 날짜를 `localStorage`에 최근 5개까지 자동 보관하는 기록 장치 추가.
  3. **학습 진도율 대시보드 (`LearningProgress.vue`)**
     - 홈 화면 중앙에 22개 핵심 문서 기준 **진도율(%)** 및 프로그레스 바 노출.
     - 최근 방문 기록 및 완료 지식 리스트 노출로 즉시 이동(숏컷) 지원.
     - **로컬 데이터 삭제 및 안내**: `localStorage` 동작 원리 가이드 제공 및 `[데이터 초기화]` 버튼을 통해 모든 기록을 삭제할 수 있는 영구 초기화 로직 구현.
  4. **개발자 유틸리티 툴킷 (`DevTools.vue` & `/docs/tools/devtools.md`)**
     - **JSON Formatter/Viewer**: 들여쓰기 2칸/4칸 및 한 줄 압축 기능 제공.
     - **Base64/URL 변환기**: 텍스트 상호 인코딩/디코딩 지원.
     - **정규식 테스터**: 정규표현식 패턴 검증 및 매칭 구절 실시간 하이라이트 제공.
     - **JWT 디코더**: 헤더와 페이로드 파싱 및 만료시간 경고 배너 실시간 계산.
     - 100% 클라이언트 브라우저 구동 방식으로 사내 망 등에서도 보안 유출 걱정 없이 단독 실행 지원.
  5. **메뉴 링크 연동**: `.vitepress/config.mts` 내 사이드바 메뉴에 `개발자 유틸리티 (DevTools)` 신규 등록 완료.

## 검증 가이드 (2차 고도화)
### 1. 학습 진도율 대시보드 테스트
1. 메인 홈페이지 (`/`)로 접속하여 중앙의 **"나의 학습 현황 및 진도율"** 카드가 정상적으로 노출되는지 확인합니다.
2. 특정 지식 문서(예: "백엔드 개발에 대한 정보")로 이동하여 상단의 **`[학습 완료]`** 버튼을 누릅니다.
3. 메인 홈페이지로 돌아왔을 때, 전체 이수율 퍼센티지가 상승하고 **"최근 완료한 지식"** 및 **"최근 방문 기록"** 목록에 해당 문서 정보가 정상적으로 매핑되었는지 확인합니다.
4. 대시보드 우측 상단의 **`[데이터 초기화]`** 버튼을 누른 뒤, 브라우저 스토리지 값이 완전히 소멸하고 진도율이 0%로 초기화되는지 확인합니다.

### 2. 개발자 유틸리티 테스트
1. 사이드바 혹은 상단 메뉴를 통해 **"개발자 유틸리티 (DevTools)"** 페이지로 접속합니다.
2. 4개의 탭(JSON 포맷터, Base64/URL 변환, 정규표현식 테스트, JWT 디코더)이 미니멀하고 직관적인 디자인으로 동작하는지 확인합니다.
3. 임의의 텍스트나 토큰을 기입하고 변환/디코딩 실행 결과가 1초 내에 실시간으로 동작하며, `[복사]` 버튼 클릭 시 정상 복사되는지 검증합니다.
