# Command R+ (Cohere) 상세 정보

[🔙 이전 화면으로 돌아가기](/docs/llm/)

---

## 📌 모델 개요
기업용(B2B) 환경과 검색 증강 생성(RAG, 외부 문서를 참고해 답변하는 기술)에 특화된 모델입니다.

## 🔍 상세 심층 분석
Command R+는 기업을 위한 AI 솔루션을 전문으로 하는 Cohere에서 개발한 최상위 엔터프라이즈급 모델입니다.

**심층 특징:**
- **최고 수준의 RAG 특화:** 사내 위키, PDF 문서 등 기업 내부 데이터를 검색하고 이를 바탕으로 정확한 답변을 생성하는 RAG(Retrieval-Augmented Generation) 아키텍처에 가장 잘 맞춰져 있습니다. 출처(Citation)를 명확하게 표기하는 능력이 탁월합니다.
- **다단계 도구 사용 (Multi-step Tool Use):** 여러 개의 API나 외부 소프트웨어 도구를 순차적 혹은 병렬적으로 호출하여 복잡한 비즈니스 프로세스를 자동화할 수 있습니다.
- **10개 주요 언어 최적화:** 영어뿐만 아니라 한국어, 일본어, 프랑스어 등 글로벌 비즈니스에 필수적인 10개 언어에 대해 깊은 이해도를 갖추고 있습니다.
