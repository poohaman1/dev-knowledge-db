## 📌 모델 개요
마이크로소프트의 초소형 언어 모델(sLM) 끝판왕으로, 스마트폰 내장 AI 시대를 완성한 모델입니다.

## 🔍 상세 심층 분석
Phi-5는 '작은 고추가 맵다'는 것을 증명하는 마이크로소프트의 sLM(Small Language Model) 시리즈 최신작입니다.

**심층 특징:**
- **완전한 On-Device AI:** 인터넷 연결 없이, 비행기 안이나 보안이 철저한 오프라인 환경에서도 스마트폰, 노트북의 자체 칩셋만으로 구동됩니다.
- **초정제 데이터 학습 (Textbook-quality):** 쓰레기 데이터를 철저히 배제하고 교과서 수준의 논리적인 데이터만 학습시켜, 작은 뇌(파라미터)로도 천재적인 논리력을 발휘합니다.
- **IoT 기기 결합:** 라즈베리 파이나 소형 로봇, 드론 등에 탑재되어 실시간으로 환경을 분석하고 제어하는 두뇌 역할을 합니다.
