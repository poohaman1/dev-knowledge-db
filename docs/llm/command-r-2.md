# Command R 2 (Cohere) 상세 정보

[🔙 이전 화면으로 돌아가기](/docs/llm/)

---

## 📌 모델 개요
기업용 문서 검색(RAG)과 복잡한 에이전트 워크플로우 자동화에 가장 특화된 B2B 전용 모델입니다.

## 🔍 상세 심층 분석
Command R 2는 철저하게 기업 환경과 비즈니스 생산성 향상을 목적으로 개발된 Cohere의 주력 모델입니다.

**심층 특징:**
- **RAG 특화 1위:** 사내의 방대한 PDF, 노션, 데이터베이스 자료를 검색하여 답변을 만들고, 정확히 몇 페이지 몇 번째 줄에서 정보를 가져왔는지 출처를 명확히 표시합니다.
- **다중 도구(Tool) 컨트롤:** 기업의 사내 시스템(Jira, Salesforce, Slack 등) API를 모델이 직접 호출하여 작업을 지시하고 결과를 받아오는 능력이 탁월합니다.
- **엄격한 데이터 프라이버시:** 기업 데이터를 학습에 사용하지 않고 완전히 격리된 환경에서 안전하게 구동할 수 있도록 설계되었습니다.
