## 📌 모델 개요
구글이 제공하는 대표적인 속도 중심의 무료 개방형 모델입니다. (최신 차세대 업그레이드 모델인 **[Gemini 3.6 Flash](/docs/llm/gemini-3-6-flash.md)**의 이전 버전)

## 🔍 상세 심층 분석
Gemini 3.5 Flash는 극강의 응답 속도와 저렴한(또는 무료) 비용을 목표로 설계된 경량화 모델입니다.

**심층 특징:**
- **초저지연(Ultra-Low Latency):** 사용자가 질문을 마치기도 전에 답변의 첫 단어를 생성하기 시작할 정도로 반응성이 뛰어납니다.
- **가성비의 끝판왕:** 무료 플랜에서도 상당한 양의 API 호출을 지원하여, 초기 스타트업이나 개인 개발자들의 웹/앱 서비스 백엔드로 가장 널리 쓰입니다.
- **핵심 멀티모달 지원:** 가벼우면서도 이미지와 짧은 영상을 빠르게 인식할 수 있어 모바일 기기의 카메라 연동 앱 등에 적합합니다.

> 💡 **참고:** 한층 더 빨라진 Sub-50ms 처리 속도와 강화된 에이전트 멀티모달 능력을 갖춘 최신 모델을 확인하시려면 **[Gemini 3.6 Flash 상세 안내](/docs/llm/gemini-3-6-flash.md)** 문서를 참고하세요.
