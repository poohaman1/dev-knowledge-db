# Step-2 / StepFun (지웨스단) 상세 정보

[🔙 이전 화면으로 돌아가기](/docs/llm/)

---

## 📌 모델 개요
**Step-2**는 마이크로소프트(Microsoft) 글로벌 부사장을 역임한 장창(Jiang Chang) 박사가 설립한 중국의 차세대 AI 유니콘 **지웨스단(StepFun / 阶跃星辰)**의 **최신 플래그십 파운데이션 모델**입니다.

Step-2는 **1조 개(1 Trillion) 이상의 파라미터를 보유한 초거대 MoE(Mixture of Experts) 아키텍처**를 기반으로 훈련되었으며, 언어 이해뿐만 아니라 멀티모달 음성/시각 인식(Step-1V), 자율 지능형 에이전트 구동에서 중국 시장 내 최상위 성능을 인정받고 있습니다.

---

## 🔍 상세 심층 분석

### 🌟 4대 핵심 특징

1. **1조(1T) 파라미터 희소(Sparse) MoE 아키텍처**
   - 수십 개의 전문 서브 네트워크(Expert) 중 입력 토큰에 최적화된 전문가만을 동적 활성화하여, 1조 급의 지능 파워를 유지하면서도 고속 추론 비용을 극소화했습니다.

2. **초고해상도 시각 인식 및 공간 기하학 추론 (Step-1V / Step-2V)**
   - 수백만 픽셀의 의료 영상, 자율주행 도로 상황 영상, 복잡한 인쇄 회로 기판(PCB) 설계도면을 픽셀 단위로 분해하여 정밀 추론합니다.

3. **고난도 수학 및 복합 과학 추론**
   - 물리 시뮬레이션 공식, 화학 반응식, 고등 대수학 문제에서 GPT-4o급의 강력한 문제 해결력을 제공합니다.

4. **소비자용 AI 어시스턴트 생태계 (유에원 / 跃问 & 마오보 / 冒泡鸭)**
   - 개인화된 지식 검색과 다중 페르소나 롤플레잉 에이전트 인프라로 폭넓게 활용되고 있습니다.
