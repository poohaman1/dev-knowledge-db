# Llama 3D (Meta) 상세 정보

[🔙 이전 화면으로 돌아가기](/docs/llm/)

---

## 📌 모델 개요
단순한 텍스트를 넘어 3D 모델과 공간 지능(Spatial Intelligence)을 이해하는 차세대 모델입니다.

## 🔍 상세 심층 분석
Llama 3D는 텍스트 중심의 LLM을 넘어, 프롬프트만으로 3D 그래픽 에셋을 생성하고 가상 공간의 물리법칙을 이해하는 메타의 메타버스/게임 연동 특화 모델입니다.

**심층 특징:**
- **텍스트 to 3D 생성:** "게임에 쓸 낡은 중세 시대 철검을 만들어줘"라고 입력하면 게임 엔진(Unity, Unreal)에 즉시 적용 가능한 3D 파일(obj, gltf)을 생성합니다.
- **공간 추론 능력:** 로봇이 물리적 공간에서 어떻게 움직여야 하는지, 사물을 어떻게 조작해야 하는지에 대한 공간 제어 지능이 뛰어나 로보틱스 산업의 핵심으로 쓰입니다.
- **오픈 비전 생태계:** 기존 Llama 텍스트 모델의 추론 능력 위에 시각/공간 처리 능력을 더하여 AR/VR 콘텐츠 제작의 장벽을 허물고 있습니다.
