# Claude Haiku 5.5 (Anthropic) 상세 정보

> [!IMPORTANT]
> **📅 최신 공식 릴리즈: 2026년 10월 16일 기준 Anthropic 최신 경량 고속 모델 (GA)**  
> **Claude Haiku 5.5**(`claude-haiku-5-5`)는 2026년 10월 7일 출시된 최신 모델로, 1M 토큰 컨텍스트와 적응형 사고를 탑재한 초저지연·대량 처리 특화 모델입니다.

[🔙 이전 화면으로 돌아가기](/docs/llm/)

---

## 📌 모델 개요
**Claude Haiku 5.5**는 Anthropic이 대량 트래픽 처리와 초저지연(Latency)이 필수적인 프로덕션 작업을 위해 출시한 최신 경량 AI 모델입니다.

경량 체급 최초로 **100만 토큰(1M) 컨텍스트 윈도우**와 **128k 최대 출력 토큰**, 그리고 `effort` 매개변수 기반의 **적응형 사고(Adaptive Thinking)**를 지원하여, 대규모 문서 요약, 고속 함수 호출, 에이전트 루프의 가성비를 극대화합니다.

---

## 🔍 핵심 기능
1. **1M 컨텍스트 & 128k 출력**: 경량 모델임에도 대용량 데이터를 일괄 적재하고 분석 가능
2. **적응형 사고 기본 탑재**: 별도 설정 없이도 질문 난이도에 맞게 효율적으로 사고
3. **최신 컴퓨터 사용 도구 세트**: `computer_toolset_20260801` 지원
