## 📌 모델 개요
**StarCoder 2**는 허깅페이스(Hugging Face)와 서비스나우(ServiceNow)가 주도하는 빅코드(BigCode) 프로젝트에서 개발한 개방형 오픈소스 코딩 전문 대형 언어 모델입니다.

## 🔍 상세 심층 분석
The Stack v2 데이터셋을 기반으로 엄격한 오픈소스 라이선스 검증과 옵트아웃(Opt-out) 권리를 보장하며 투명하게 학습된 개발자 친화 모델입니다.

**심층 특징:**
- **600개 이상의 프로그래밍 언어 지원:** 메이저 언어는 물론 코볼(COBOL), 포트란(Fortran), 얼랭(Erlang) 등 비인기/레거시 언어까지 완벽 대응합니다.
- **3B, 7B, 15B 다양한 크기 제공:** 3B 모델은 노트북이나 엣지 디바이스에서도 초당 수십 토큰으로 돌아가며, 15B 모델은 실무 코드 어시스턴트로 최적입니다.
- **16k 컨텍스트 및 인필링(Fill-in-the-Middle):** 코드 완성 중간 삽입(FIM) 기능을 지원하여 IDE 내 인라인 자동완성 툴 구축에 탁월합니다.
