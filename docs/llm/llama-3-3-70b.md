# Llama 3.3 70B (Meta) 상세 정보

[🔙 이전 화면으로 돌아가기](/docs/llm/)

---

## 📌 모델 개요
**Llama 3.3 70B**는 Meta가 공개한 Llama 3 시리즈의 최종 완성형 모델로, 이전 세대의 초대형 405B 모델과 대등한 인텔리전스를 70B라는 현실적인 체급에 압축하여 담아낸 오픈소스 표준 모델입니다.

## 🔍 상세 심층 분석
단일 또는 듀얼 GPU(RTX 3090/4090 및 A100 등) 서버에서 원활하게 가동할 수 있어, 기업 및 스타트업이 자체 호스팅(On-Premise)으로 운영하기에 가장 이상적인 비용 효율성을 제공합니다.

**심층 특징:**
- **128k 컨텍스트 윈도우:** 장문의 문서 요약과 복잡한 멀티 턴 대화를 손실 없이 처리합니다.
- **최상급 코딩 및 다국어 지원:** 8개 국어 이상의 고품질 다국어 데이터와 최신 프로그래밍 언어 코퍼스를 학습했습니다.
- **풍부한 생태계 호환성:** vLLM, Ollama, Hugging Face, TensorRT-LLM 등 모든 오픈소스 인프라에서 최적화된 양자화와 가속을 지원합니다.
