# DBRX (Databricks) 상세 정보

[🔙 이전 화면으로 돌아가기](/docs/llm/)

---

## 📌 모델 개요
데이터 전문 기업 데이터브릭스에서 만든 강력한 MoE 오픈소스 모델입니다. 코딩과 프로그래밍 작업에 최적화되어 있습니다.

## 🔍 상세 심층 분석
DBRX는 빅데이터 및 AI 플랫폼 기업인 Databricks(데이터브릭스)가 100억 원 이상을 투자하여 밑바닥부터 자체 개발한 강력한 오픈소스 LLM입니다.

**심층 특징:**
- **세밀한 MoE 아키텍처 (Fine-grained MoE):** Mixtral과 같은 MoE 구조이지만, 훨씬 더 잘게 쪼개진 16개의 전문가 신경망을 사용하고 이 중 4개를 조합하여 사용함으로써 효율과 성능을 극대화했습니다. (총 132B 파라미터 중 36B만 추론에 활성화)
- **코딩 및 SQL 특화:** 데이터브릭스의 태생적 특징답게, 프로그래밍 코드 작성과 데이터베이스를 다루는 SQL 쿼리 생성 능력이 다른 오픈소스 모델들을 압도합니다.
- **엔터프라이즈 환경 최적화:** 기업들이 보안 문제로 데이터를 외부로 내보내지 못할 때, 사내 서버에 구축하여 자체 코딩 어시스턴트나 데이터 분석 봇을 만들기 좋은 모델입니다.
