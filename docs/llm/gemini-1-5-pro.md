## 📌 모델 개요
구글의 최상위 AI 모델로, 엄청나게 큰 컨텍스트 윈도우(최대 200만 토큰)를 자랑합니다.

## 🔍 상세 심층 분석
Gemini 1.5 Pro는 구글 딥마인드에서 개발한 최상위 멀티모달 AI 모델로, 이전 세대인 Gemini 1.0 Ultra와 비견되는 성능을 지니면서도 훨씬 효율적입니다.

**심층 특징:**
- **초거대 컨텍스트 윈도우:** 기본 100만 토큰, 최대 200만 토큰의 컨텍스트를 지원합니다. 이는 1시간 분량의 비디오, 11시간 분량의 오디오, 3만 줄 이상의 코드, 70만 단어 이상의 텍스트를 한 번에 처리할 수 있음을 의미합니다.
- **정보 검색 능력 (Needle In A Haystack):** 수백만 토큰의 방대한 데이터 속에서도 특정 정보를 99% 이상의 정확도로 찾아내는 압도적인 검색 능력을 보유하고 있습니다.
- **MoE (Mixture-of-Experts) 아키텍처:** 작업을 처리할 때 전체 신경망을 모두 사용하지 않고, 관련성 높은 특정 전문가 신경망만 활성화하여 효율성을 극대화했습니다.
