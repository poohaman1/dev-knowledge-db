# Llama 5 (Meta) 상세 정보

[🔙 이전 화면으로 돌아가기](/docs/llm/)

---

## 📌 모델 개요
오픈소스 생태계를 이끄는 Meta의 5세대 모델. 유료 모델들을 위협하는 강력한 오픈소스입니다.

## 🔍 상세 심층 분석
Llama 5는 전 세계 AI 개발자 커뮤니티의 기반이 되는 Meta의 최신 오픈소스 언어 모델입니다.

**심층 특징:**
- **완벽한 오픈소스 생태계:** 수만 명의 개발자가 만든 플러그인, 파인튜닝 가이드, 양자화(Quantization) 도구들이 Llama 5를 중심으로 즉시 구축되어 있습니다.
- **로컬 구동 최적화:** 무거운 400B 이상의 대형 모델뿐만 아니라, 노트북이나 스마트폰에서 구동되는 가벼운 경량 모델 라인업의 성능이 극대화되었습니다.
- **개선된 추론 엔진:** Llama 4에 비해 수학적 증명, 코딩, 다국어 처리 능력이 획기적으로 상승하여 상업용(Closed) 모델을 사용할 필요성을 줄여줍니다.
