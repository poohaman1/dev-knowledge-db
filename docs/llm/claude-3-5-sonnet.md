# Claude 3.5 Sonnet (Anthropic) 상세 정보

[🔙 이전 화면으로 돌아가기](/docs/llm/)

---

## 📌 모델 개요
**Claude 3.5 Sonnet**은 Anthropic이 선보인 지능과 가성비, 속도의 황금 밸런스를 갖춘 글로벌 표준 AI 모델입니다.

개발자 커뮤니티에서 폭발적인 인기를 끌며 Cursor, Windsurf, GitHub Copilot 등 유수의 AI 코딩 도구의 기본 모델로 자리 잡았으며, 업계 최초로 화면을 보고 마우스와 키보드를 조작하는 **Computer Use(컴퓨터 사용)** API를 선보였습니다.

---

## 🔍 상세 심층 분석

### 🌟 핵심 주요 기능

1. **업계 최초 Computer Use (컴퓨터 조작) API 도입**
   - AI가 화면의 스크린샷을 분석하여 마우스 커서를 이동하고, 클릭하며, 텍스트를 입력하고, 애플리케이션을 실행할 수 있습니다.
   - 복잡한 웹 폼 자동 작성, UI 테스트 자동화, 소프트웨어 설치 및 실행 등 기존 텍스트 한계를 뛰어넘는 에이전트 작업을 지원합니다.

2. **독보적인 코드 리팩토링 및 아키텍처 이해**
   - 높은 수준의 문맥 파악 능력을 통해 레거시 코드의 냄새(Code Smell)를 빠르게 파악하고 모던 디자인 패턴으로 리팩토링합니다.
   - 프론트엔드 React/Vue 컴포넌트부터 복잡한 SQL 쿼리 최적화까지 실무 개발에서 높은 신뢰도를 제공합니다.

3. **Artifacts (아티팩트) 실시간 렌더링**
   - 웹 대화 인터페이스에서 SVG 그래픽, React 인터랙티브 컴포넌트, HTML/CSS 웹 페이지, 다이어그램을 우측 분할 화면에 즉시 렌더링하여 보여줍니다.

4. **인간다운 대화 어조와 낮은 거부율**
   - 불필요한 사과나 기계적인 응답을 지양하고, 전문 엔지니어와 협업하는 듯한 자연스럽고 통찰력 있는 답변을 제공합니다.

## 📊 주요 사양

| 항목 | 상세 내용 |
| :--- | :--- |
| **컨텍스트 윈도우** | 200,000 토큰 (약 15만 단어 / 500페이지) |
| **최대 출력 토큰** | 8,192 토큰 |
| **멀티모달 지원** | 텍스트, 이미지, 문서(PDF), 차트 완벽 지원 |
| **대표 도구 연동** | Cursor, Windsurf, Continue.dev, Claude Web, AWS Bedrock, GCP Vertex AI |
