## 📌 모델 개요
**Yi-Lightning**은 글로벌 AI 석학 카이푸 리(Kai-Fu Lee)가 설립한 01.AI에서 발표한 최신 초고속 MoE 언어 모델로, LMSYS 챗봇 아레나 글로벌 상위권을 기록하며 놀라운 가성비와 속도를 증명한 모델입니다.

## 🔍 상세 심층 분석
독창적인 동적 라우팅 MoE 아키텍처를 도입하여 토큰 생성 속도를 대폭 가속하면서도 복잡한 수학, 코딩, 논리적 글쓰기에서 최고 수준의 일관성을 유지합니다.

**심층 특징:**
- **초저지연 고속 토큰 생성:** 동급 모델 대비 2배 이상 빠른 생성 속도를 보여주며 실시간 대화형 서비스에 최적화되었습니다.
- **LMSYS 챗봇 아레나 글로벌 TOP 10 기록:** 오픈/상용 모델 통합 벤치마크에서 글로벌 최정상급 모델들과 대등한 승률을 기록했습니다.
- **파격적인 API 경제성:** 고품질 추론 능력을 극도로 저렴한 API 단가로 제공하여 대규모 트래픽을 처리하는 엔터프라이즈 환경에 적합합니다.
