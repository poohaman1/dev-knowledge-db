# Gemini 3.6 Flash (Google) 상세 정보

[🔙 이전 화면으로 돌아가기](/docs/llm/)

---

## 📌 모델 개요
**Gemini 3.6 Flash**는 Gemini 3.5 Flash의 성공을 잇는 Google DeepMind의 초고속·고효율 경량 모델입니다. (최신 하이브리드 추론 플래그십 업그레이드 모델인 **[Gemini 3.7 Flash](/docs/llm/gemini-3-7-flash.md)** 출시)

> 💡 **최신 모델 안내:** 하이브리드 사고(Thinking Mode) 제어와 압도적인 코딩 성능을 탑재한 최신 플래그십 모델은 **[Gemini 3.7 Flash 상세 안내](/docs/llm/gemini-3-7-flash.md)** 문서에서 확인하실 수 있습니다.

## 🔍 상세 심층 분석
Gemini 3.6 Flash는 실시간 서비스 운영과 멀티 에이전트 시스템에 최적화된 구글의 핵심 AI 엔진입니다.

### 🌟 4대 핵심 혁신 기능

1. **Sub-50ms Ultra-Fast Latency (초저지연 실시간 응답)**
   - 첫 단어 출력 시간(TTFT, Time To First Token)을 50ms 미만으로 극단적으로 축소하여, 실시간 음성 대화 및 라이브 스트리밍 에이전트에 최적화되었습니다.

2. **Enhanced Agentic Multimodal Reasoning (에이전트 멀티모달 추론)**
   - 단순한 이미지 인식 수준을 넘어, 동영상 스트림, 실시간 화면 UI, 오디오 노이즈를 동시에 다중 분석하고 곧바로 에이전트 도구(Tool)를 호출하는 능력이 획기적으로 향상되었습니다.

3. **High-Speed Million-Token Context Window (고속 100만 토큰 컨텍스트)**
   - 100만 토큰 이상의 매머드급 컨텍스트 윈도우를 Gemini 3.5 Flash 대비 **2배 빠른 처리 속도**로 정보 손실 없이 탐색합니다.

4. **Developer-Friendly API & Zero-Cost Tier (개발자 친화적 에코시스템)**
   - Google AI Studio 및 Vertex AI에서 풍부한 무료 쿼리 한도를 제공하여 개인 개발자부터 스타트업까지 부담 없이 글로벌 서비스를 구축할 수 있습니다.

## 📊 Gemini 3.5 Flash vs Gemini 3.6 Flash 주요 비교

| 비교 항목 | Gemini 3.5 Flash | Gemini 3.6 Flash (New ✨) |
| :--- | :--- | :--- |
| **첫 토큰 생성 속도 (TTFT)** | ~150ms 내외 | **Sub-50ms (실시간 스트리밍 대화 가능)** |
| **컨텍스트 처리 속도** | 표준 고속 | **Gemini 3.5 Flash 대비 2배 향상** |
| **에이전트 도구 호출 (Tool Call)** | 기본 지원 | **멀티모달 실시간 화면/음성 연동 에이전트 특화** |
| **개발자 요금 정책** | 넉넉한 무료 티어 | **동일 수준의 넉넉한 무료 티어 유지 + 성능 대폭 상향** |
