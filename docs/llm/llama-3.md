## 📌 모델 개요
메타(페이스북)가 공개한 오픈소스 진영의 최강자입니다.

## 🔍 상세 심층 분석
Llama 3는 Meta(메타)가 공개한 오픈소스 LLM(초거대 언어 모델) 제품군입니다. 8B(80억 파라미터)와 70B(700억 파라미터) 모델이 오픈소스로 제공되며, 오픈소스 생태계를 이끄는 핵심 모델입니다.

**심층 특징:**
- **압도적인 오픈소스 성능:** 70B 모델의 경우 GPT-4나 Claude 3 Sonnet에 필적하거나 앞서는 성능을 보여주며 오픈소스 진영의 기준(Standard)을 완전히 높였습니다.
- **방대한 학습 데이터:** 무려 15T(15조) 토큰이라는 어마어마한 양의 고품질 데이터로 학습되어 모델의 기본기 자체가 매우 탄탄합니다.
- **쉬운 배포 및 튜닝:** 가벼운 8B 모델은 개인 노트북의 GPU 하나로도 쉽게 구동하고 파인튜닝(Fine-tuning)할 수 있어 AI 연구자 및 학생들에게 필수적인 툴로 자리 잡았습니다.
