## 📌 모델 개요
**o3-mini**는 OpenAI가 복잡한 수학, 코딩, 과학(STEM) 분야의 심층 문제 해결을 위해 설계한 차세대 초고속 추론 특화 소형 모델(sLM)입니다.

## 🔍 상세 심층 분석
플래그십 모델인 o3의 핵심 추론 역량을 경량화하여 지연 시간(Latency)을 획기적으로 줄이고, 개발자가 추론 노력 수준(Reasoning Effort: Low / Medium / High)을 직접 제어할 수 있도록 설계되었습니다.

**심층 특징:**
- **단계별 추론 강도 제어:** API 파라미터를 통해 가벼운 코딩에는 Low, 복잡한 알고리즘 증명에는 High를 선택하여 비용과 속도를 최적화할 수 있습니다.
- **개발자 중심의 도구 지원:** 함수 호출(Function Calling), 구조화된 JSON 출력(Structured Outputs), 시스템 프롬프트(Developer Messages)를 완벽하게 지원합니다.
- **압도적인 코딩 벤치마크:** SWE-bench Verified 및 주요 코딩 테스트에서 대형 플래그십 모델을 상회하는 정답률을 보여줍니다.
