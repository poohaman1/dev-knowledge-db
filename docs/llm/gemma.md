## 📌 모델 개요
구글의 Gemini 기술을 바탕으로 만든 오픈소스(개방형) 경량 모델입니다.

## 🔍 상세 심층 분석
Gemma(젬마)는 구글이 자사의 최상위 AI인 Gemini를 개발하면서 얻은 기술과 인프라를 바탕으로 만든 오픈형(Open-weights) 경량 언어 모델입니다.

**심층 특징:**
- **Gemini의 DNA:** Gemini와 동일한 기술적 구조를 상당 부분 공유하고 있어, 가벼우면서도 구글 특유의 강력한 자연어 처리 능력을 보유하고 있습니다.
- **쉬운 개발 환경 연동:** 구글이 만든 모델답게 Keras, JAX, PyTorch 등 주요 머신러닝 프레임워크와 완벽하게 호환되며, Kaggle, Colab 등에서 즉시 사용할 수 있는 환경이 잘 구축되어 있습니다.
- **2B와 7B 라인업:** 20억 개, 70억 개 파라미터 두 가지 크기로 제공되며 연구, 상업적 이용이 모두 허용되는 유연한 라이선스를 제공합니다.
