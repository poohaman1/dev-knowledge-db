## 📌 모델 개요
마이크로소프트의 sLM(Small Language Model). 스마트폰에 들어갈 정도로 매우 작지만, 강력한 성능을 갖췄습니다.

## 🔍 상세 심층 분석
Phi-3는 마이크로소프트가 개발한 소형 언어 모델(sLM, Small Language Model) 시리즈입니다. '크기가 전부가 아니다'라는 것을 증명한 획기적인 모델입니다.

**심층 특징:**
- **교과서 수준의 고품질 데이터:** 모델 크기를 무작정 키우는 대신, 아이들에게 엄선된 교과서를 읽히듯 극도로 정제되고 수준 높은 데이터(Textbook quality data)만을 엄선하여 학습시켰습니다.
- **초소형 사이즈 (On-Device AI):** 파라미터 수가 불과 38억(3.8B) 개인 Phi-3-Mini는 아이폰이나 최신 안드로이드 스마트폰의 내부 칩셋만으로 인터넷 연결 없이 작동할 수 있습니다.
- **크기 대비 놀라운 추론력:** 10배 이상 큰 오픈소스 모델들과 맞먹는 코딩, 수학, 논리 능력을 보여주어 엣지 디바이스(Edge Device) 기반 AI의 새 장을 열었습니다.
