## 📌 모델 개요
**DeepSeek-V4**는 오픈소스 AI 연구소 DeepSeek가 발표한 **1조 개(1T) 파라미터 규모의 차세대 전문가 혼합(MoE)** 오픈소스 플래그십 모델입니다.

총 1T 파라미터 중 각 토큰을 처리할 때 **48B 파라미터만 동적으로 활성화**하는 극강의 연산 효율을 자랑하며, 독자 기술인 **MLA 2.0(다중 헤드 잠재 어텐션 2세대)**을 통해 상용 최고 수준의 성능을 저비용 오픈소스로 제공합니다.

---

## 🔍 상세 심층 분석

### 🌟 4대 핵심 아키텍처 혁신

1. **Multi-head Latent Attention 2.0 (MLA 2.0)**
   - KV 캐시 메모리 압축률을 95%까지 끌어올려 단일 서버 노드에서도 100만 토큰 분량의 대규모 소스코드를 메모리 병목 없이 실시간 분석합니다.

2. **Ultra-Fine Granularity MoE (초미세 전문가 분할)**
   - 512개의 전문화된 서브 네트워크로 지식을 세분화하여 복잡한 도메인(컴파일러, 커널, 시스템 엔지니어링, 고등수학)에서 상용 유료 모델을 능가하는 정확도를 보여줍니다.

3. **순수 강화학습(RL) 기반의 자가 진화 추론 엔진**
   - 별도의 지도학습(SFT) 라벨링 없이도 자발적인 오류 반성과 논리 검증을 수행하는 DeepSeek-R2의 핵심 추론 엔진이 기본 탑재되었습니다.

4. **MIT 라이선스 완전 공개**
   - 상업적 목적의 무제한 활용, 자체 수정 및 사내 프라이빗 호스팅(On-Premise)이 완전히 보장됩니다.
