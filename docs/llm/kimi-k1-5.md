## 📌 모델 개요
**Kimi k1.5**는 문샷 AI(Moonshot AI)가 개발한 차세대 멀티모달 추론 모델로, 200만 토큰에 달하는 무손실 롱 컨텍스트와 강화학습 기반의 자율 에이전트 추론 기능을 완벽하게 융합한 모델입니다.

## 🔍 상세 심층 분석
수십 권 분량의 서적이나 수천 장의 PDF 도면, 고해상도 비디오를 한 번에 입력받아도 '바늘 찾기(Needle in a Haystack)' 벤치마크 100%를 달성하는 탁월한 기억 회상 성능을 자랑합니다.

**심층 특징:**
- **200만 토큰 무손실 롱 컨텍스트:** 대규모 논문집, 기업 재무제표, 장편 소설을 통째로 분석하여 정확한 인용과 교차 검증을 제공합니다.
- **멀티모달 시각 추론:** 복잡한 차트, 표, 기계 도면, 손글씨 메모를 정밀하게 판독하고 수식과 논리를 시각적으로 증명합니다.
- **에이전트 검색 및 리서치:** 사용자 질문에 대해 인터넷 다중 검색과 문서 요약을 병렬 수행하여 고품질 심층 리포트를 생성합니다.
