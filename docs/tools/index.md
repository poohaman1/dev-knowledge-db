# 🛠 유용한 개발 도구 (Tools)

개발 생산성을 극대화시켜주는 **차세대 AI 자율 코딩 에이전트, 고성능 IDE, 초고속 런타임 및 패키지 매니저, API 테스트 도구, 서버리스 BaaS, 터미널 및 아키텍처 디자인 도구**를 카테고리별로 총망라하여 제공합니다.

## ⚡ 3. 초고속 런타임, 번들러 & 패키지 매니저
빌드 및 의존성 설치 속도를 수배에서 수십 배 단축시켜주는 모던 개발 툴체인입니다.

| 도구명 | 공식 링크 | 추천 이유 및 핵심 기능 |
| :--- | :--- | :--- |
| **[Bun](https://bun.sh)** | https://bun.sh | Node.js를 대체하는 초고속 올인원 JavaScript/TypeScript 런타임, 번들러, 테스트 러너 및 패키지 매니저 |
| **[uv (Astral)](https://github.com/astral-sh/uv)** | https://github.com/astral-sh/uv | Rust 기반으로 pip 대비 10~100배 빠른 차세대 Python 패키지 인스톨러, 가상환경 및 프로젝트 매니저 |
| **[pnpm](https://pnpm.io)** | https://pnpm.io | 하드링크 및 심볼릭 링크 기반으로 디스크 공간을 절약하고 모노레포(Monorepo)에 최적화된 고속 패키지 관리자 |
| **[Vite](https://vitejs.dev)** | https://vitejs.dev | Rollup과 esbuild 기반의 네이티브 ESM을 활용하여 초고속 HMR(Hot Module Replacement)을 제공하는 모던 프론트엔드 빌드 툴 |
| **[Biome](https://biomejs.dev)** | https://biomejs.dev | Prettier와 ESLint를 Rust로 하나로 통합하여 단일 실행 파일로 극도의 포매팅 및 린팅 속도를 제공하는 도구 |
| **[Turborepo](https://turbo.build/repo)** | https://turbo.build/repo | Vercel의 Rust 기반 고성능 모노레포 빌드 시스템. 원격 캐싱(Remote Caching)을 통한 빌드 시간 극적 단축 |
| **[Volta](https://volta.sh)** | https://volta.sh | Node.js, npm, yarn, pnpm 버전을 프로젝트별 `package.json` 선언에 맞춰 매끄럽게 자동 스위칭해주는 Rust 도구 |

## 🌐 4. API 개발, 네트워크 디버깅 & 자동화 테스팅
안정적인 백엔드 통신 및 E2E 브라우저 테스트를 위한 필수 소프트웨어입니다.

| 도구명 | 공식 링크 | 추천 이유 및 핵심 기능 |
| :--- | :--- | :--- |
| **[Bruno](https://www.usebruno.com)** | https://www.usebruno.com | Git 리포지토리에 API 컬렉션을 일반 텍스트(Bru DSL)로 보관하여 팀원과 안전하게 버전 관리하는 오프라인 오픈소스 클라이언트 |
| **[Playwright](https://playwright.dev)** | https://playwright.dev | Microsoft의 최신 E2E 테스트 및 헤드리스 브라우저 자동화 프레임워크 (크롬, 파이어폭스, 웹킷 완벽 지원) |
| **[Hoppscotch](https://hoppscotch.io)** | https://hoppscotch.io | 프로그램 설치 없이 웹 브라우저에서 즉시 실행 가능한 가볍고 미려한 웹 기반 오픈소스 API 개발 도구 |
| **[Postman](https://www.postman.com)** | https://www.postman.com | API 설계, 모의 서버(Mock Server), 문서화, 자동화 모니터링 및 대규모 엔터프라이즈 팀 협업 플랫폼 |
| **[HTTPie](https://httpie.io)** | https://httpie.io | curl보다 직관적인 터미널 문법과 컬러풀한 JSON 출력을 제공하는 모던 CLI 및 데스크톱 HTTP 클라이언트 |
| **[Proxyman](https://proxyman.io)** | https://proxyman.io | macOS 및 Windows를 지원하는 네이티브 고성능 HTTP/HTTPS 패킷 캡처, SSL 프록시 및 API 모킹 도구 |
