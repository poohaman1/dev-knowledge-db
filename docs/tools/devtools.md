# ⚙️ 개발자 유틸리티 (DevTools)

본 유틸리티 도구 세트는 개발 시 빈번하게 필요한 가벼운 편의 도구를 웹사이트 내에서 바로 사용할 수 있도록 제공합니다.

> [!IMPORTANT]
> **개인정보 및 보안 안내 (Privacy First)**
> * 본 페이지의 모든 도구(JSON 포맷터, Base64 변환기, 정규식 테스터, JWT 디코더)는 **100% 사용자의 웹 브라우저(클라이언트) 내부에서만 구동**됩니다.
> * 입력하신 데이터나 토큰 등은 외부 백엔드 서버로 절대로 전송되지 않으므로 사내 보안 유출 염려 없이 안심하고 사용하셔도 좋습니다.

### 💡 주요 유틸리티 활용 팁
1. **JSON 포맷터**: 외부 API 응답 데이터가 한 줄로 복잡하게 나올 때 붙여넣어 `들여쓰기` 버튼을 누르면 가독성 높은 구조로 자동 포맷팅됩니다.
2. **Base64 / URL 변환**: 웹 통신이나 API 파라미터 전달 시 특수문자 처리를 위한 인코딩/디코딩이 실시간으로 이루어집니다.
3. **정규표현식 테스터**: 자바스크립트의 `RegExp` 표준 엔진 기반으로 동작하며 매칭 결과를 즉시 시각적으로 표시해 줍니다.
4. **JWT 디코더**: 토큰의 서명 검증은 생략하고 내부의 클레임(Claim) 정보 및 만료 시간(`exp`)만 즉시 파싱하여 토큰 유효 여부를 쉽게 진단합니다.
