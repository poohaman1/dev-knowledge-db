# 💡 개발자 지식DB 2차 고도화 제안서 (비로그인/정보 제공형 서비스 타겟)

본 제안서는 **로그인 및 회원가입 기능 없이** 개발자들에게 실질적인 가치를 제공하고, 사이트의 유입 트래픽과 체류 시간을 극대화할 수 있는 2차 기능 고도화 방안을 제시합니다. 서버 유지 비용 $0(무료)의 정적 사이트(VitePress) 아키텍처를 그대로 유지하면서 클라이언트 사이드 기술을 100% 활용하는 방안 위주로 구성되어 있습니다.

---

## 1. 비로그인 기반 핵심 고도화 기능 제안

### 1.1. 로컬 데이터(localStorage) 기반 '나의 학습 진도율 대시보드'
* **개요**: 로그인 없이 사용자의 브라우저 저장소를 활용하여 읽은 문서나 로드맵의 완료 여부를 체크하고 진도율을 시각화합니다.
* **상세 구현**:
  * 로드맵 노드 및 개별 기술 문서 하단에 `[학습 완료 Check]` 버튼 제공.
  * 완료 상태를 `localStorage`에 저장하여 브라우저 재방문 시에도 유지.
  * 홈 화면 상단 또는 사이드바 영역에 전체 진도율 프로그레스 바(Progress Bar) 및 성취도 그래프 시각화.
* **기대 효과**: 개인화된 학습 경험 제공을 통해 재방문율(Retention)을 향상시킵니다.

### 1.2. 클라이언트 사이드 '개발자 유틸리티 툴킷 (DevTools)' 구축
* **개요**: 개발자들이 일상 업무 중에 빈번하게 사용하는 가벼운 편의 도구를 웹사이트 내 한 페이지에서 제공합니다.
* **상세 구현**:
  * 별도의 서버 통신 없이 100% 프론트엔드 JavaScript로 구동되는 유틸리티 페이지 개설.
  * **도구 라인업**:
    * **JSON Formatter/Viewer**: JSON 데이터를 정렬하고 에러를 체크하는 도구.
    * **Base64 / URL Encoder & Decoder**: 데이터 인코딩/디코딩 편의 도구.
    * **Regex Tester**: 정규표현식을 실시간으로 매칭해보고 테스트하는 도구.
    * **JWT Decoder**: JWT 토큰의 Payload를 로그인 없이 안전하게 파싱해주는 도구.
* **기대 효과**: "도구를 쓰기 위해 매일 즐겨찾기로 방문하는" 반복적인 트래픽(Recurring Traffic)을 유입시키고 지식 콘텐츠로의 자연스러운 연계를 유도합니다.

### 1.3. 브라우저 히스토리 기반 '최근 본 문서' 및 '연관 문서 추천'
* **개요**: 사용자가 이전에 읽었던 문서 목록을 제공하고, 현재 읽고 있는 문서와 관련된 유용한 기술 가이드를 추천합니다.
* **상세 구현**:
  * `localStorage`에 최근 방문한 5개의 문서 ID(경로)를 기록하여 하단 퀵 위젯에 노출.
  * 현재 문서의 카테고리(예: Backend, Architecture) 분석을 통해 연관도가 높은 다른 핵심 가이드를 하단에 자동 추천(추천 알고리즘을 빌드 시 혹은 Vue 컴포넌트 내에 매핑).
* **기대 효과**: 이탈률(Bounce Rate)을 대폭 낮추고 하나의 세션 내에서 여러 문서를 유기적으로 학습하도록 유도합니다.

### 1.4. 인터랙티브 '코드 플레이그라운드 (Live Code Editor)'
* **개요**: 프로그래밍 언어나 가이드라인에 등장하는 예제 코드를 다른 사이트로 이동할 필요 없이 본 사이트 내에서 즉시 수정하고 실행 결과를 확인하는 샌드박스입니다.
* **상세 구현**:
  * HTML, CSS, JavaScript 또는 간단한 프론트엔드 코드를 라이브로 실행할 수 있는 에디터(Monaco Editor 또는 단순 textarea 기반) 임베딩.
  * iframe 샌드박스 혹은 WebAssembly 기반의 경량 런타임을 연동하여 브라우저에서 안전하게 코드 실행.
* **기대 효과**: 단순 텍스트 학습에서 벗어나 '실험하며 배우는' 인터랙티브 학습 환경을 구축하여 정보의 질을 차별화합니다.

### 1.5. 개발자 커뮤니티 바이럴용 '스마트 공유 & 클립보드 복사'
* **개요**: 유용한 지식 문서나 코드 스니펫을 사내 Slack, Discord, 카카오톡 등에 최적화된 형식으로 빠르게 전파할 수 있도록 돕습니다.
* **상세 구현**:
  * **Slack/Discord 맞춤형 복사**: 클릭 한 번으로 제목, 핵심 요약 요약글, 사이트 링크가 깔끔한 Markdown 인용문 형식으로 정리되어 클립보드에 저장됨.
  * **SNS 요약 이미지 생성**: HTML5 Canvas를 이용해 문서 제목과 핵심 요약이 포함된 이쁜 카드 이미지를 즉석 생성하여 다운로드/복사할 수 있게 지원.
* **기대 효과**: 개발자 간의 자연스러운 정보 공유 본능을 활용하여 외부 트래픽 유입을 크게 늘릴 수 있습니다.

## 2. 2차 고도화 기능 기술 비교표

| 기능명 | 데이터 저장 방식 | 필요 외부 라이브러리 | 서버 유지 비용 | 난이도 | 우선순위 |
| :--- | :--- | :--- | :--- | :--- | :--- |
| **나의 학습 진도율 대시보드** | LocalStorage (로컬) | 없음 (CSS/JS 자체 구현) | $0 (Zero) | 하 | **상 (1순위)** |

## 3. 향후 개발 제안 방향성

1. **우선순위 1**: 로그인 없이 바로 효용을 느낄 수 있는 **'나의 학습 진도율 대시보드'**를 로드맵과 연계하여 개발합니다.
2. **우선순위 2**: 지속적인 트래픽 자석 역할을 해줄 **'개발자 유틸리티 툴킷'**을 추가하여 정보 제공 뿐 아니라 유용한 도구 사이트로서의 정체성을 강화합니다.
