# 🐚 Bash / Shell Script 상세 가이드

> **"검은 화면(터미널) 너머의 운영체제(OS) 심장을 직접 통제하고 자동화하는 엔지니어의 만능 칼"**

---

## 💡 1. 30년차 선배의 쉬운 설명
많은 초보 개발자들이 마우스로 윈도우 창을 클릭해가며 폴더를 만들고 파일을 옮기고 빌드 프로그램을 실행합니다. 하지만 서버 컴퓨터나 클라우드 환경에서는 눈에 보이는 마우스나 GUI 화면이 없습니다. 오직 검은 터미널 창과 키보드 타이핑만 존재합니다.

**Bash(배시) / 쉘 스크립트**는 이 검은 창에서 리눅스/유닉스 운영체제(OS)의 커널에 직접 명령을 내리는 스크립팅 언어입니다. 파일 압축, 서버 배포, 환경 설정, 주기적인 백업 작업 등 시스템 인프라 전반을 코드로 자동화할 때 뼈대 역할을 담당합니다.

*   **비유하자면:** 무전기를 들고 건물(서버) 내부의 모든 경비대원과 설비 제어실에 직접 지시를 내려 건물 전체를 일사분란하게 가동하고 순찰하게 만드는 사령관의 직접 통신망과 같습니다.

---

## 🛠️ 2. 어디에 주로 쓰이나요?
1.  **리눅스 서버 인프라 운영:** 클라우드 서버 세팅, 권한 조정, 폴더 정리 및 프로세스 가동.
2.  **CI/CD 배포 파이프라인 자동화:** GitHub Actions나 Jenkins 등 빌드 서버에서 코드를 압축하고, 테스트를 돌린 뒤, 실서버에 코드를 전송하여 배포하는 일련의 과정을 쉘 스크립트로 자동화합니다.

---

## ⚖️ 3. 장점과 단점 (선배의 솔직 한마디)
*   **장점 (비교 불가한 신속함):**
    *   **즉각적인 자동화:** 복잡한 프로그램 설치나 컴파일 없이, 리눅스 명령어들을 파일에 모아 적어두기만 하면 몇 만 대의 컴퓨터에서도 즉시 똑같은 세팅이 가능합니다.
    *   **서버 마스터의 첫걸음:** 쉘 스크립트를 다룰 수 있게 되는 순간 단순 코더를 넘어 시스템 엔지니어의 눈을 뜨게 됩니다.
*   **단점 (비직관적인 디버깅):**
    *   **난해한 문법:** 조건문 괄호 띄어쓰기(`[ $a -eq 1 ]`)나 변수 선언 시 띄어쓰기 불허 등 특유의 까다롭고 올드한 규칙 때문에 문법 오류를 잡기 다소 번거롭습니다.

## 🚀 4. 초보자를 위한 첫걸음 코드
특정 폴더가 존재하지 않으면 자동으로 만들고 백업본을 복사하는 기본 자동화 쉘 스크립트입니다.

```bash
#!/bin/bash

# 1. 백업할 대상 폴더 경로를 지정합니다.
TARGET_DIR="./docs"
BACKUP_DIR="./backup_folder"

# 2. 만약 백업할 폴더가 존재하지 않는다면(! -d) 새로 생성합니다.
if [ ! -d "$BACKUP_DIR" ]; then
  echo "⚠️ 백업 폴더가 없습니다. 새로 생성합니다..."
  mkdir -p "$BACKUP_DIR"
fi

# 3. 대상 폴더 안의 모든 마크다운 파일을 백업 폴더로 복사합니다.
cp $TARGET_DIR/*.md $BACKUP_DIR/
echo "✅ 백업이 정상 완료되었습니다: $(date)"
```

## 🎯 5. 초보자 추천 공부 방향
1.  윈도우 환경이라면 Git Bash나 WSL(Windows Subsystem for Linux)을 설치해 리눅스 터미널 환경을 먼저 세팅하세요.
2.  `cd`, `ls`, `mkdir`, `cp`, `mv`, `rm` 등 **기초 쉘 명령어 10가지**를 키보드 단축키처럼 외워 몸에 익히는 것이 출발선입니다.
3.  기본 문법을 깊이 파기보단, **AI 코딩 어시스턴트**에게 "A 폴더의 파일을 날짜별로 정리하는 쉘 스크립트 짜줘"라고 한 뒤 코드를 뜯어보며 실행 구조를 역추적하는 학습법을 추천합니다. AI가 쉘 스크립트 생성을 무척 잘하기 때문입니다.
