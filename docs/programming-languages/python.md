## 🚀 4. 초보자를 위한 첫걸음 코드
파이썬의 간결함과 가독성이 돋보이는 함수 예제입니다.

```python
# 1. 함수를 정의합니다 (들여쓰기로 블록을 구분합니다)
def evaluate_career(years):
    if years >= 10:
        return "당신은 이미 훌륭한 시니어 엔지니어이십니다!"
    else:
        return "차근차근 실력을 쌓아가는 성장형 개발자이시군요!"

# 2. 함수를 실행하고 콘솔에 출력합니다.
dev_years = 3
result_msg = evaluate_career(dev_years)
print(f"경력: {dev_years}년 -> {result_msg}")
```
