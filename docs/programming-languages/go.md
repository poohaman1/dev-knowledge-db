# 🐹 Go (Golang) 상세 가이드

> **"구글이 대규모 트래픽 처리와 마이크로서비스(MSA) 인프라를 위해 깎아 만든 단단하고 극도로 효율적인 컴파일러 언어"**

---

## 💡 1. 30년차 선배의 쉬운 설명
웹 서비스의 규모가 엄청나게 커져서 네이버, 유튜브 같은 대형 사이트가 되면 컴퓨터 한 대로는 수만 명의 접속자를 감당할 수 없습니다. 이때 서버의 자원을 낭비하지 않고, 가장 빠르고 안정적으로 일꾼(스레드)들을 나누어 일을 시킬 수 있는 초경량 언어가 필요해졌는데, 그것이 바로 구글이 개발한 **Go(고랭)** 입니다.

C++은 너무 복잡하고 배우기 어려우며 실수하기 쉽고, Python이나 Java는 서버의 메모리를 상대적으로 많이 먹습니다. Go는 이 중간의 균형을 기가 막히게 잡아냈습니다. 문법이 극도로 단순하여 책 한 권이면 며칠 만에 마스터할 수 있고, 실행 속도는 C언어 수준으로 빠르며 컴파일 결과물이 단 하나의 실행파일(`.exe` 등)로 뚝딱 나와 배포가 정말 편리합니다.

*   **비유하자면:** 불필요한 무게와 옵션을 전부 빼버린, 레이싱과 속도 배달만을 위해 최적화된 뼈대 굵은 스포츠 바이크(오토바이)와 같습니다.

---

## 🛠️ 2. 어디에 주로 쓰이나요?
1.  **클라우드 및 인프라 시스템:** 현대 클라우드 인프라의 표준 도구인 **Docker(도커)** 와 **Kubernetes(쿠버네티스)** 가 100% Go 언어로 작성되었습니다.
2.  **고성능 마이크로서비스 백엔드:** 대용량 트래픽 처리용 웹 서버 API 및 MSA 환경의 핵심 엔진으로 맹활약합니다.

---

## ⚖️ 3. 장점과 단점 (선배의 솔직 한마디)
*   **장점 (깔끔함과 안정성):**
    *   **압도적 성능 & 경량화:** 메모리를 매우 적게 먹고, 고루틴(`Goroutine`)이라는 내장 기능을 활용해 동시성 연산을 수십만 개씩 안전하게 처리합니다.
    *   **문법의 통일:** 정답 코드가 거의 하나로 통일되므로, 누가 작성한 코드를 보더라도 똑같이 읽기 쉬워 협업 효율이 뛰어납니다.
*   **단점 (지나친 단순화):**
    *   **클래스 상속 없음:** 전통적인 객체지향(Java 등)의 상속 개념이 없고 구조체와 인터페이스만 지원하여 초기 설계 시 어색할 수 있습니다.
    *   **보일러플레이트 코드:** 코드를 짤 때 에러 체크 문구(`if err != nil`)가 수없이 반복되는 귀찮음이 존재합니다.

## 🚀 4. 초보자를 위한 첫걸음 코드
Go 언어 특유의 가볍고 직관적인 동시성 처리(Goroutine) 기본 코드입니다.

```go
package main

import (
	"fmt"
	"time"
)

// 일꾼이 백그라운드에서 실행할 독립 함수입니다.
func sayHello(workerID int) {
	fmt.Printf("일꾼 %d번: 백그라운드 작업 시작!\n", workerID)
}

func main() {
	// 'go' 키워드 하나로 메인 실행 흐름과 별개인 초경량 스레드(고루틴)를 즉시 띄웁니다.
	go sayHello(1)
	go sayHello(2)

	// 고루틴이 완료될 시간을 잠깐 벌어줍니다.
	time.Sleep(100 * time.Millisecond)
	fmt.Println("메인 서버: 모든 비동기 명령 전송 완료!")
}
```

## 🎯 5. 초보자 추천 공부 방향
1.  Go는 공식 튜토리얼인 [A Tour of Go](https://go.dev/tour/) 사이트가 정말 잘 구성되어 있습니다. 이 튜토리얼을 꼭 한 번 정주행해 보세요.
2.  포인터(`*`, `&`)의 개념을 가볍게 이해한 다음, **구조체(Struct)**와 **인터페이스(Interface)**를 활용해 데이터를 묶어 다루는 실습을 해보세요.
3.  Go의 표준 패키지(`net/http`)만으로 외부 프레임워크 없이 웹 서버를 구축해보는 연습을 하면 웹 백엔드의 기본 동작 원리가 저절로 깨우쳐집니다.
