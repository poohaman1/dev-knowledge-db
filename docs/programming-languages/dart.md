# 🎯 Dart 상세 가이드

> **"구글이 Flutter라는 크로스플랫폼 날개를 달아주어 전성기를 맞이한, 한 번의 코딩으로 안드로이드와 iOS를 동시 폭격하는 명사수"**

---

## 💡 1. 30년차 선배의 쉬운 설명
과거에는 안드로이드 앱과 iOS 앱을 만들려면 각각 Kotlin(안드로이드)과 Swift(iOS)를 따로 공부해 코드를 따로 두 번 짰어야 했습니다. 1인 스타트업이나 소규모 팀에게는 개발 기간과 비용이 두 배로 드는 지옥 같은 작업이었죠. 

**Dart(다트)**는 바로 이 지옥에서 밧줄을 던져 준 구글의 **Flutter(플러터)** 프레임워크 전용 프로그래밍 언어입니다. 다트는 자바, C#, 자바스크립트의 장점들을 고루 섞어 문법을 만들었습니다. 덕분에 자바나 자바스크립트를 할 줄 아는 개발자라면 단 몇 시간 만에 문법을 터득할 수 있을 정도로 익숙합니다. 

*   **비유하자면:** 하나의 운전대로 안드로이드(좌핸들)와 iOS(우핸들) 차량을 모두 동시에 조종해버리는 만능 운전면허증과 같습니다.

## 🛠️ 2. 어디에 주로 쓰이나요?
1.  **Flutter 크로스플랫폼 앱 개발:** 하나의 Dart 코드베이스로 안드로이드, iOS 모바일 앱은 물론이고 웹사이트, macOS/Windows 데스크톱 프로그램까지 한 방에 통짜 컴파일하여 출시합니다.

## ⚖️ 3. 장점과 단점 (선배의 솔직 한마디)
*   **장점 (시간 단축 끝판왕):**
    *   **Hot Reload (핫 리로드):** 코드를 고치고 저장 버튼만 누르면, 폰에 켜져 있는 앱 화면이 0.5초 만에 바뀌어 개발 피드백 속도가 환상적입니다.
    *   **쉬운 학습 난이도:** 문법이 매우 규칙적이고 상식적이라 오류를 낼 요인이 적습니다.
*   **단점 (Flutter 의존성):**
    *   **플러터 외의 사용처 부족:** 플러터 프레임워크가 아닌 독립적인 웹 백엔드나 시스템 프로그래밍 분야에서는 다트 언어 단독으로 쓰이는 일이 거의 없습니다.

## 🚀 4. 초보자를 위한 첫걸음 코드
다트의 깔끔하고 정제된 클래스 선언과 동적 문자열 템플릿 코드입니다.

```dart
class App {
  String name;
  String platform;

  // 생성자 단축 문법
  App(this.name, this.platform);

  void run() {
    print('🚀 $name 앱이 $platform 환경에서 실행되었습니다!');
  }
}

void main() {
  // Dart는 가벼운 선언과 실행을 지향합니다.
  var myApp = App('지식DB 모바일', 'Android/iOS');
  myApp.run();
}
```
