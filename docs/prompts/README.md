# 🤖 프롬프트 모음 (Prompts)

AI 언어 모델(Claude, Gemini, ChatGPT, Grok 등)을 개발 업무에 활용할 때 바로 쓸 수 있는 **실전 프롬프트 모음**입니다.

> [!TIP]
> 프롬프트의 `[ ]` 괄호 부분을 실제 내용으로 교체하여 AI 모델에 질문하세요. 기본 템플릿은 `templates/PROMPT-TEMPLATE.md`를 참고하세요.

---

## 🧑‍💻 코드 작성 및 리팩토링

### 코드 리뷰 요청
```text
다음 [언어/프레임워크] 코드를 시니어 엔지니어의 관점에서 리뷰해 주세요.
클린 코드, SOLID 원칙, 성능, 보안 취약점 순서로 검토하고,
각 문제점에 대해 Before/After 코드를 함께 제시해 주세요.

[코드 삽입]
```

### 함수/클래스 설명 요청
```text
다음 코드가 어떤 역할을 하는지 설명해 주세요.
1. 전체 목적을 2~3줄로 요약
2. 핵심 로직 단계별 설명
3. 주의해야 할 엣지 케이스

[코드 삽입]
```

### 리팩토링 요청
```text
다음 코드를 [목표: 성능 개선 / 가독성 향상 / 중복 제거] 관점에서 리팩토링해 주세요.
변경 전후를 비교하고, 왜 그렇게 변경했는지 이유를 한국어로 설명해 주세요.

[코드 삽입]
```

## 🐛 디버깅 및 에러 해결

### 에러 원인 분석
```text
다음 에러 메시지가 발생했습니다. 원인과 해결 방법을 알려주세요.

[에러 환경: OS, 언어, 프레임워크 버전 등]
[에러 로그]
[관련 코드]

가장 가능성 높은 원인 3가지와 각각의 해결책을 제시해 주세요.
```

### 무한루프 / 성능 병목 분석
```text
다음 코드에서 성능 병목이 발생하고 있습니다.
시간 복잡도를 분석하고, Big-O 개선 방안을 코드와 함께 제시해 주세요.

[코드 삽입]
```

## 🏗️ 아키텍처 및 설계

### 시스템 설계 요청
```text
[서비스 목적 및 규모]를 위한 백엔드 아키텍처를 설계해 주세요.
- 사용 기술 스택: [프레임워크, DB, 캐시 등]
- 예상 트래픽: [MAU 혹은 RPS]
- 핵심 요구사항: [기능 목록]

Mermaid 다이어그램과 함께 각 컴포넌트의 역할, 통신 방식, 데이터 흐름을 설명해 주세요.
```

### DB 스키마 설계
```text
[서비스명]의 핵심 기능인 [기능 목록]을 위한 데이터베이스 스키마를 설계해 주세요.
- DB 종류: [MySQL / PostgreSQL / MongoDB 등]
- ERD 다이어그램 (Mermaid 형식)
- 인덱스 전략 및 이유
```

## 📝 문서화 및 설명

### README 작성
```text
다음 프로젝트의 README.md를 작성해 주세요.
- 프로젝트명: [이름]
- 목적: [한 줄 설명]
- 기술 스택: [목록]
- 핵심 기능: [목록]

설치 방법, 환경 변수 설정, 실행 방법, API 예시를 포함하고
뱃지(Badge)와 이모지를 활용해 시각적으로 보기 좋게 작성해 주세요.
```

### Git 커밋 메시지 생성
```text
다음 변경 사항을 기반으로 Conventional Commits 규칙에 맞는 커밋 메시지 3가지를 제안해 주세요.
각 메시지는 타입(feat/fix/docs/refactor 등), 범위, 설명을 포함해야 합니다.

변경 요약: [내용]
주요 변경 파일: [목록]
```

## 🔍 AI 활용 및 프롬프트 개선

### 프롬프트 최적화
```text
다음 프롬프트를 LLM이 더 정확하게 이해하고 고품질의 결과를 낼 수 있도록 개선해 주세요.
- 원본 프롬프트: [내용]
- 목표 결과물: [원하는 형태]
- 개선 방향: 모호한 표현 제거, 출력 형식 명확화, 예시(Few-shot) 추가
```

### 프롬프트 체인 작성
```text
[복잡한 작업]을 여러 단계로 나누어 처리하는 프롬프트 체인을 설계해 주세요.
각 단계의 입력과 출력을 명확히 정의하고, 단계 간 데이터 전달 방법도 설명해 주세요.
```
