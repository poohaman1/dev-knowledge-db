## 1. 전자상거래법상 '다크패턴(눈속임 상술) 19개 유형' 전면 규제 🇰🇷

개정 전자상거래법에 따라 이용자의 착오를 유도하여 불필요한 지출을 유발하는 **6대 범주 19개 다크패턴 유형**이 법적으로 전면 금지되며, 위반 시 시정명령 및 과태료가 부과됩니다.

```
┌─────────────────────────────────────────────────────────────┐
│ 🚫 금지되는 대표적 다크패턴 6대 핵심 범주                   │
├─────────────────────────────────────────────────────────────┤
│ 1. 숨은 갱신 (Hidden Subscription):                         │
│    👉 무료 체험 후 사전 명시적 통지 없이 유료 구독 자동 전환 및 결제
├─────────────────────────────────────────────────────────────┤
│ 2. 취소/탈퇴 방해 (Hard to Cancel):                         │
│    👉 가입은 원클릭, 해지는 복잡한 5단계 설문이나 유선 전화 강제  │
├─────────────────────────────────────────────────────────────┤
│ 3. 순차 공개 가격 책정 (Drip Pricing):                      │
│    👉 첫 화면엔 저렴한 가격 노출 후, 최종 결제 단계에서 필수 배송비/수수료 기습 추가
├─────────────────────────────────────────────────────────────┤
│ 4. 특정 옵션 사전 선택 (Pre-selection):                     │
│    👉 추가 유료 옵션(보험, 정기배송 등) 체크박스를 기본값으로 활성화
├─────────────────────────────────────────────────────────────┤
│ 5. 잘못된 유인 및 거짓 카운트다운 (False Urgency):          │
│    👉 실제 재고/시간 제한이 없음에도 "마감 5분 전! 재고 1개!" 허위 표시
├─────────────────────────────────────────────────────────────┤
│ 6. 감정적 압박 (Confirmshaming):                            │
│    👉 "아니오, 저는 혜택을 버리고 손해를 보겠습니다" 등 수치심 유발 문구
└─────────────────────────────────────────────────────────────┘
```

## 2. 웹/앱 서비스 푸터 필수 고지 항목 (통신판매업) 🇰🇷

온라인에서 유료 결제나 구독 서비스를 운영하는 모든 웹사이트 및 앱은 푸터(Footer) 또는 설정 화면에 다음 정보를 영구 고지해야 합니다:

```html
<!-- 웹/앱 하단 필수 표기 표준 -->
<footer>
  <p>상호명: (주)엔지니어스튜디오 | 대표자: 홍길동</p>
  <p>사업자등록번호: 123-45-67890 | 통신판매업신고번호: 제2026-서울강남-0000호</p>
  <p>사업장 주소: 서울특별시 강남구 테헤란로 123 | 고객센터: 02-1234-5678 (help@example.com)</p>
  <p>호스팅서비스 제공자: AWS / Vercel</p>
  <p>
    <a href="/terms">이용약관</a> | 
    <a href="/privacy"><strong>개인정보처리방침</strong></a> |

  </p>
</footer>
```

## 3. 앱스토어 (Apple / Google) 심사 정책과 결제 규제 🌐

1. **인앱결제 강제 금지와 외부 결제 아웃링크**:
   - 대한민국 전기통신사업법 개정에 따라 외부 웹 결제 링크 제공이 가능해졌으나, 앱마켓 사업자(애플·구글)의 규정에 따라 외부 결제 이용 시에도 약 **26%~27%의 마켓 수수료**가 부과되며 정해진 인앱 브라우저 가이드라인을 준수해야 합니다.
2. **계정 및 데이터 즉시 삭제 의무화**:
   - 앱 내에서 회원가입이 가능한 앱은 반드시 **앱 내에서 계정 탈퇴 및 관련 데이터 삭제 요청을 즉시 처리할 수 있는 직관적인 UI**를 제공해야 심사가 통과됩니다.

## 4. 웹 접근성 법적 의무 (KWCAG 2.2 준수) 🇰🇷

장애인차별금지법 제14조에 따라 모든 공공 및 민간 웹/앱 서비스는 장애인과 고령자가 차별 없이 이용할 수 있도록 웹 접근성을 보장해야 합니다.

```
[웹 접근성 4대 원칙 체크리스트]
1. 인식의 용이성: 모든 이미지에 적절한 대체 텍스트(alt) 제공, 텍스트/배경 명암비 4.5:1 이상
2. 운용의 용이성: 마우스 없이 키보드(Tab, Enter)만으로 모든 메뉴와 기능 조작 가능
3. 이해의 용이성: 입력 폼 오류 시 시각적 표시와 함께 텍스트 에러 메시지 및 포커스 이동
4. 견고성: 최신 W3C 표준 문법 준수 및 스크린 리더 호환 ARIA 랜드마크(role, aria-live) 적용
```

## 5. 온라인 플랫폼 공정화 및 알고리즘 투명성 🇰🇷

- **검색 및 추천 알고리즘의 공정성**:
  - 입점 업체 간 순위 산정 시 광고 결제 여부, 자사 직매입 상품 우대 등 알고리즘을 조작하여 부당하게 자사 상품을 상단에 노출하는 행위 금지.
  - 이용자에게 추천 순위 산정의 주요 기준(인기도, 판매량, 리뷰 점수 등)을 투명하게 안내해야 합니다.
