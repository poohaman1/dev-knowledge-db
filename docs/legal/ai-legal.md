# 🤖 AI 및 생성형 AI 관련 법률 이슈

> [!WARNING]
> **⚖️ 법적 면책 고지**: 본 문서는 빠르게 변화하는 인공지능 관련 최신 판례, 입법 동향, 국제 규제를 바탕으로 한 정보 제공용 문서입니다. 실제 AI 모델 출시, 학습 데이터 수집, 서비스 제공 시에는 전담 법률 자문(변호사, 변리사)을 구하시기 바랍니다.  
> **🌐 주요 관할권**: 🇰🇷 대한민국 (인공지능 기본법안, 저작권법 개정안), 🇪🇺 유럽연합 (EU AI Act), 🇺🇸 미국 (판례법, FTC/USPTO/USCO 가이드라인)

## 1. EU AI Act 전면 시행과 글로벌 규제 체계 🇪🇺

유럽연합의 **EU AI Act(인공지능법)**는 세계 최초의 포괄적 AI 규제 법률로, 전 세계에 서비스하는 모든 기업에 역외 적용됩니다.

```
┌─────────────────────────────────────────────────────────────┐
│ 1. 금지된 AI (Unacceptable Risk)                            │
│    👉 인지 조작, 사회적 신용 평가(Social Scoring), 공공장소 실시간 생체인식 (전면 금지)
├─────────────────────────────────────────────────────────────┤
│ 2. 고위험 AI (High Risk)                                    │
│    👉 채용·인사 평가, 대출 심사, 의료 기기, 필수 인프라, 자율주행
│    👉 품질 관리 시스템, 데이터 거버넌스, 설명가능성, 인간 감독(Human-in-the-loop) 의무화
├─────────────────────────────────────────────────────────────┤
│ 3. 범용 AI 모델 (General Purpose AI - GPAI)                 │
│    👉 LLM 파운데이션 모델(GPT, Claude 등)의 기술 문서 작성, EU 저작권법 준수 의무
│    👉 고영향 시스템적 위험 모델: 적대적 평가(Red-teaming), 에너지 효율성 보고
├─────────────────────────────────────────────────────────────┤
│ 4. 최소/투명성 위험 AI (Minimal Risk)                        │
│    👉 AI 챗봇 및 딥페이크: AI와 대화 중임을 알리는 표시, AI 생성물 워터마크 부착
└─────────────────────────────────────────────────────────────┘
```

> **⚠️ 위반 시 제재**: 최대 **3,500만 유로(약 500억 원) 또는 전 세계 연간 매출의 7%** 중 높은 금액의 천문학적 과징금 부과.

## 2. 대한민국 인공지능(AI) 기본법 및 규제 동향 🇰🇷

1. **고영향 인공지능(High-Impact AI) 사전 고지 및 신뢰성 확보**:
   - 국민의 생명, 신체, 기본권에 중대한 영향을 미치는 AI 시스템(채용, 의료, 신용평가 등)을 운영하는 기업은 사용자에게 **사전 고지**하고, **위험관리 및 설명가능성 확보 조치**를 취해야 합니다.
2. **AI 생성물 워터마크 표시 의무화**:
   - 텍스트, 이미지, 음성, 비디오 등 생성형 AI를 통해 제작된 산출물에는 이용자가 AI 생성물임을 명확히 인지할 수 있도록 가시적/비가시적 디지털 워터마크(C2PA 표준 등)를 부착해야 합니다.
3. **인공지능안전연구소(AI Safety Institute) 설립**:
   - 첨단 프런티어 모델의 안전성 검증 및 적대적 레드팀(Red-Teaming) 평가 제도화.

## 3. 학습 데이터 저작권 침해와 TDM(텍스트·데이터 마이닝) 🇰🇷 🇺🇸 🇪🇺

- **저작물 무단 크롤링/학습 분쟁**:
  - 뉴스 기사, 오픈소스 코드, 서적, 이미지 등을 LLM 사전 학습에 투입하는 행위가 공정이용(Fair Use)에 해당하는지를 두고 뉴욕타임스(NYT) 대 OpenAI, 게티이미지 대 스태빌리티AI 등 글로벌 소송 지속.
- **관할권별 TDM 면책 규정 비교**:
  - **🇪🇺 EU (DSM 지침 제4조)**: 저작권자가 기계 판독 가능한 수단(robots.txt, HTTP 헤더 등)으로 **명시적 거부(Opt-out)**를 선언하지 않은 경우 상업적 TDM 허용.
  - **🇺🇸 미국**: 변혁적 이용(Transformative Use) 요건 충족 여부에 따라 공정이용 인정 여부가 갈림.
  - **🇰🇷 한국**: 저작권법 개정안을 통해 정당한 권원에 의해 접근한 저작물에 대한 TDM 면책 조항 입법 추진 중.

## 4. AI 생성물의 저작권 귀속과 특허 인정 여부 🇰🇷 🇺🇸

- **인간의 창작적 기여 요건 (Human Authorship Requirement)**:
  - 🇺🇸 **미국 저작권청 (USCO)**: 단순한 프롬프트 입력만으로 생성된 결과물은 저작권 등록 불가(Thaler v. Perlmutter 항소심 확정). 인간이 직접 편집·가공·배치한 창작적 기여 부분만 선별 등록 허용.
  - 🇰🇷 **한국 저작권위원회**: AI는 민법상 권리주체가 아니므로 저작자가 될 수 없으며, 순수 AI 생성물은 저작권 보호 대상에서 제외.
- **AI의 발명자 인정 여부**:
  - 미국, 한국, 유럽 특허청 모두 "특허법상 발명자는 자연인(인간)에 한정된다"는 원칙을 일관되게 유지(DABUS 판결).

## 5. 오픈소스 AI(OSAID 1.0)와 모델 라이선스 체계 🌐

Open Source Initiative(OSI)가 공식 발표한 **Open Source AI Definition (OSAID 1.0)** 기준:

```
진정한 오픈소스 AI의 3대 조건:
1. Data Information: 학습 데이터셋의 상세 출처, 수집 방식, 데이터 필터링 내역 공개
2. Source Code: 학습, 미세조정(Fine-tuning), 전처리, 추론에 사용된 전체 소스코드 공개
3. Model Parameters: 모델 가중치(Weights)와 아키텍처 사양 전면 공개
```

### 📋 주요 상용/커뮤니티 AI 라이선스 구분
- **MIT / Apache 2.0 (DeepSeek-V4, Qwen 일부 등)**: 아무런 제약 없이 상용 서비스 및 수정, 재배포 가능.
- **Llama Community License (Meta)**: 상업적 이용 가능하나, MAU 7억 명 이상 플랫폼의 경우 별도 라이선스 계약 요구 및 경쟁 모델 학습 금지 조건 부여.
- **RAIL (Responsible AI License)**: 비윤리적 목적(가짜뉴스, 군사 무기, 차별적 감시 등) 사용을 금지하는 행동 제한적 라이선스.

## 6. 기업용 생성형 AI 도입 시 실무 법률 체크리스트

```
[개발사 및 기업 내부 거버넌스 수칙]
☑️ API 제공사와의 Zero Data Retention (ZDR) 계약 체결 여부 (고객 데이터 학습 재사용 금지)
☑️ 사내 소스코드의 섀도우 AI(Shadow AI) 무단 입력 방지 보안 솔루션 구축
☑️ AI 코딩 도구(Cursor, Copilot 등) 사용 시 라이선스 오염(GPL 전염 방지) 코드 스캔 수행
☑️ 서비스 약관에 "AI 기술이 적용된 기능"임을 명시하고 환각(Hallucination) 관련 책임 한계 고지
☑️ 딥페이크 및 AI 생성 콘텐츠에 대한 투명성 워터마크(C2PA 메타데이터) 삽입 프로세스 검증
```
